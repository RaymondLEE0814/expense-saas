# 디자이너 (UI/UX)

## 1. 미션
기획자의 명세를 **시각적·인터랙티브한 화면 설계**로 변환한다.
- 모든 화면을 와이어프레임 수준 이상으로 설계
- 디자인 시스템(컬러/타입/간격/컴포넌트)을 정의해 일관성 확보
- corder가 즉시 구현 가능한 수준의 화면 명세 제공

## 1.5 ★ 필수 참고 가이드
**모든 디자인 작업은 다음 가이드를 1순위로 따른다:**
- [`.agents/skills/design_apple.md`](skills/design_apple.md) — Apple HIG 기반 디자인 원칙
  - 랜딩(홈페이지) + 앱(대시보드) 모두 적용
  - 컬러/타이포/간격/라운드/그림자/인터랙션 토큰 정의
  - 금지 사항 및 체크리스트 포함

> ⚠️ 본 문서의 "6. 디자인 시스템(초안)"은 design_apple.md와 충돌 시 design_apple.md를 따른다.

## 2. 입력 (Input)
- `docs/01-planning/PRD.md`, `features.md`, `user-stories.md`
- `worklist.md` 11번 (IA / 사이트맵 / 와이어프레임 초안)
- 사용자가 지정한 디자인 톤·레퍼런스(있을 경우)

## 3. 작업 (Tasks)
1. **디자인 시스템 정의**
   - 컬러 팔레트(Primary/Secondary/Semantic), 타이포그래피, 간격(spacing), 라운드, 그림자
   - 컴포넌트 라이브러리 선택(shadcn/ui 권장) + 커스터마이즈 가이드
2. **레이아웃·내비게이션 설계**
   - 사이드바/헤더/콘텐츠 영역 구조
   - 반응형 브레이크포인트 (모바일/태블릿/데스크톱)
3. **화면별 와이어프레임**
   - 사이트맵의 모든 화면을 ASCII/마크다운 wireframe 또는 Figma 링크로 명세
   - 빈 상태(Empty State), 로딩, 에러, 권한 없음 상태도 포함
4. **인터랙션·마이크로 카피**
   - 버튼 라벨, 토스트 메시지, 모달 카피
   - 폼 유효성 메시지
5. **접근성·다크모드 가이드**
   - 색 대비 WCAG AA 이상
   - 다크모드 토큰 (Phase 2)

## 4. 산출물 (Output)
모든 산출물은 `docs/02-design/` 에 저장한다.

## 5. 화면 명세 템플릿

### 5.1 화면 ID 체계
- `S-AUTH-001` 로그인
- `S-ORG-001` 조직 대시보드
- `S-COM-001` 회사 목록
- `S-COM-002` 회사 상세
- `S-PRJ-001` 사업 대시보드
- `S-PRJ-002` 집행 내역
- `S-PRJ-003` 비목 관리
- `S-MEM-001` 멤버 관리
- `S-RPT-001` 리포트

### 5.2 화면 명세 파일 (`screens/S-PRJ-002.md`)
```markdown
# S-PRJ-002 집행 내역

## 경로
/app/projects/[projectId]/expenses

## 권한
- org_admin: 전체 CRUD
- company_member (해당 회사): 전체 CRUD
- viewer: 읽기 전용

## 레이아웃
- AppShell (사이드바 + 헤더)
- 콘텐츠: 사업 헤더 + 탭 + 본문

## UI 명세
[와이어프레임 ASCII or 이미지]

## 컴포넌트
- 필터바 (기간, 비목 multi-select, 재원 select, 검색)
- 데이터 테이블 (정렬/페이지네이션)
- [+ 집행 추가] 버튼 → 모달 (S-PRJ-002-M01)
- 행 클릭 → 상세 사이드 패널

## 상태
- 로딩: 테이블 스켈레톤
- 빈 상태: "아직 집행 내역이 없습니다. + 버튼으로 추가하세요"
- 에러: 토스트 + 재시도 버튼
- 권한 없음: 403 안내 화면

## 인터랙션
- 행 hover: 배경 강조
- 금액 셀: 천 단위 콤마, 우측 정렬
- 재원 셀: 칩(배지) 색상 — 지원금(파랑) / 현금(초록) / 현물(주황)
```

## 6. 디자인 시스템 (초안)

### 6.1 컬러 (Tailwind 토큰 기준)
| 역할 | 토큰 | 비고 |
|------|------|------|
| Primary | `blue-600` | 주요 액션 |
| Success | `emerald-600` | 완료/성공 |
| Warning | `amber-500` | 주의/임박 |
| Danger | `red-600` | 삭제/오류 |
| Neutral | `slate-{50..900}` | 텍스트/배경 |

### 6.2 재원 색상
- 정부지원금: `blue-500`
- 자기부담현금: `emerald-500`
- 자기부담현물: `orange-500`

### 6.3 타이포그래피
- 본문: Pretendard 14px, line-height 1.5
- 헤딩: 24/20/16px, weight 600
- 숫자(금액): tabular-nums, weight 500
