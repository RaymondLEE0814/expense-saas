### B-002 해결 방법
1. https://supabase.com/dashboard 에서 새 프로젝트 생성
   - 이름: `expense-saas-dev` (또는 임의)
   - Region: `Northeast Asia (Seoul) ap-northeast-2`
   - DB 비밀번호 설정 (저장)
2. 프로젝트 생성 후 Settings → API 에서 다음 3개 키 확인:
   - `URL` (`https://xxx.supabase.co`)
   - `anon public` 키
   - `service_role` 키 (Secret)
3. 사용자 → PM에게 공유 (또는 직접 `.env.local` 작성 후 corder에 알림)
