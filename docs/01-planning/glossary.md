# 용어 사전 (Glossary)

> 작성자: 기획자 | 일자: 2026-05-19
> **모든 문서·UI에서 동일한 용어 사용을 강제한다.** 신규 용어 추가 시 본 문서에 먼저 등록.

## 1. 조직 / 사용자 도메인

| 한글 | 영문 / DB | 정의 |
|------|-----------|------|
| **조직** | Organization / `organizations` | 멀티 테넌트 최상위 단위. 스타트업/그룹사 1개에 해당. 예: (주)슈퍼런 |
| **회사** | Company / `companies` | 조직 내 법인. 예: 리피치, 슈퍼런, 팜큐 |
| **멤버십** | Membership / `memberships` | 사용자가 조직에 속한 관계 + 역할 |
| **역할** | Role | `org_admin`(조직 관리자) / `company_member`(회사 담당자) / `viewer`(조회자) / `super_admin`(서비스 운영자) |
| **슈퍼관리자** | Super Admin | 서비스 운영자. 전체 조직 접근 가능 (Phase 3) |
| **조직 관리자** | Org Admin | 조직 내 전체 권한 (회사·사업·비목·집행·멤버) |
| **회사 담당자** | Company Member | 본인 소속 회사의 데이터만 접근/수정 |
| **조회자** | Viewer | 조직 내 데이터를 읽기 전용으로 조회 (외부 회계사 등) |
| **초대** | Invitation | 멤버 초대 토큰 (이메일 링크) |

## 2. 사업 / 정산 도메인

| 한글 | 영문 / DB | 정의 |
|------|-----------|------|
| **사업** | Project / `projects` | 정부지원 사업 1건. 회사 아래에 속함 |
| **주관기관** | Host Agency | 사업을 주관하는 정부/공공기관 (예: 중기부, 산업부) |
| **전담기관** | Managing Agency | 사업 수행을 관리하는 기관 (예: TIPA, KEIT) |
| **사업 기간** | Project Period | 시작일 ~ 종료일 |
| **총사업비** | Total Budget | 사업의 전체 예산. 정부지원금 + 자기부담금(현금+현물) |
| **선정금액** | Selected Amount | 협약 선정 시점의 금액 (총사업비와 다를 수 있음) |
| **사업 상태** | Status | `in_progress` 진행중 / `completed` 종료 / `cancelled` 취소 |
| **D-day** | - | 사업 종료일까지 남은 일수 |

## 3. 재원 (Funding Sources)

| 한글 | 영문 / DB | 정의 |
|------|-----------|------|
| **재원** | Funding Source / `funding_sources` | 사업비의 출처 (정부지원금/자기부담현금/자기부담현물) |
| **정부지원금** | Gov Grant / `gov_grant` | 정부가 지원하는 금액 |
| **자기부담현금** | Self Cash / `self_cash` | 회사가 자체 부담하는 현금 |
| **자기부담현물** | Self In-kind / `self_in_kind` | 회사가 자체 부담하는 현물 (인건비·기존 장비 등) |

**약속**: UI에서는 "정부지원금 / 현금 / 현물" 단축형 사용 가능, 단 첫 등장 시 풀네임 노출.

## 7. 표기 규칙

### 7.1 통화
- DB: 원 단위 정수 (`numeric(15,0)`)
- UI: 천 단위 콤마 + "₩" prefix 또는 "원" suffix
- 약식 표시: 1,000,000원 → "100만원" (대시보드 한정), 1억 = 100,000,000

### 7.2 날짜
- 저장: UTC (`timestamptz`) 또는 `date`
- 표시: `YYYY-MM-DD` 또는 한국어 `YYYY년 M월 D일`
- 상대 시간: "3일 전", "방금" (Phase 2: dayjs/date-fns relative)

### 7.3 사업자번호
- 입력 시 자동 하이픈 삽입: `123-45-67890`
- DB 저장: 하이픈 없이 10자리

### 7.4 영문/한글 혼용
- DB 컬럼·코드 식별자: 영문 (snake_case)
- UI 라벨: 한글
- 도메인 용어 첫 등장 시 영문 병기 가능 (예: 사업(Project))
