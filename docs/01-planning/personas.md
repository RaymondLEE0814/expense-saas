## P1. 조직 관리자 (Org Admin) — 핵심 페르소나

**이름**: 이석진 (Raymond)
**역할**: (주)슈퍼런 그룹 대표 / 정산 책임자
**조직 상황**: 3개 법인(리피치/슈퍼런/팜큐)의 정부지원 사업 8~12건 동시 운영

### 일상 / Job To Be Done
- 매주 월요일 아침 각 회사 사업 진행 상황을 점검
- 정산 마감 1개월 전부터 일별 집행률 모니터링
- 외부 회계사·주관기관 담당자와 정산 자료 공유
- 신규 사업 선정 시 재원 구조 및 비목 설계

### 주요 고충 (Pain Points)
- "각 회사 담당자에게 매번 엑셀 받고 합치는 데 반나절"
- "비목 95% 도달했는데 알림이 없어서 초과 집행 자주 발생"
- "정산 양식이 사업마다 다른데 매번 수기 변환"

### 가치 (Gain)
- 한 화면에서 3개 회사 × 모든 사업 집행률 즉시 확인
- 비목별 잔여액과 D-day가 항상 보임
- 회사 담당자가 직접 입력 → 본인은 검토만

### 기술 친숙도
- 엑셀·Notion 능숙, 데이터 도구 익숙
- 새 SaaS 도입 의향 높음 (얼리 어답터)

### 핵심 기능 의존도 (Top 3)
1. 조직 대시보드 (전 회사 한눈에)
2. 사업 대시보드 (비목·재원·D-day)
3. 멤버 초대 + 권한 격리

## P2. 회사 담당자 (Company Member)

**이름**: (가상) 김민지
**역할**: 슈퍼런 경영지원팀 사원, 사업 행정 담당
**조직 상황**: 슈퍼런 소속, 사업 2건 담당

### 일상 / JTBD
- 사업비 카드 사용 후 거래내역 입력
- 거래처 세금계산서 수령 시 등록
- 외부 인건비 지급 시 비목 차감

### Pain Points
- "엑셀에 입력하다 보면 어느 비목인지 헷갈림 (특히 외주용역비/연구활동비 경계)"
- "관리자한테 매번 잔여액 물어봐야 함"
- "다른 회사 사업이 내 엑셀에 섞여 들어와 헷갈림"

### Gain
- 본인 회사 / 본인 담당 사업만 깔끔하게 표시
- 입력하면 즉시 잔여액 갱신
- 비목 초과 시 경고

### 기술 친숙도
- 엑셀 보통, 새 도구 학습 부담 — UI가 직관적이어야 함

### 핵심 기능 의존도 (Top 3)
1. 집행 내역 빠른 등록 (3클릭 이내)
2. 본인 사업 대시보드
3. 비목 잔여액 즉시 표시
