## AU. 인증

### US-AU-01: 이메일로 가입한다
**As a** 신규 사용자
**I want** 이메일·비밀번호로 가입하고 이메일을 인증
**So that** 본인 명의로 조직을 만들 수 있다

**인수 기준**
- Given 가입하지 않은 이메일을 가진 방문자가
- When `/signup`에서 이메일·비밀번호(8자 이상)·이름을 입력하면
- Then `profiles` 레코드가 생성되고 이메일 인증 메일이 발송된다
- And 인증 링크 클릭 시 활성화 상태가 된다

**예외**
- 이미 가입된 이메일: "이미 가입된 이메일입니다. 로그인하세요" 안내
- 비밀번호 < 8자: 인라인 에러

---

### US-AU-02: 로그인한다
**As a** 가입한 사용자
**I want** 이메일·비밀번호로 로그인
**So that** 내 조직에 접근한다

**인수 기준**
- Given 이메일 인증을 마친 사용자가
- When 올바른 자격증명을 입력하면
- Then 세션이 발급되고 `/app`으로 리다이렉트된다
- And 미인증/오류 시 명확한 에러 메시지가 표시된다

---

### US-AU-03: 비밀번호를 재설정한다
**As a** 비밀번호를 잊은 사용자
**I want** 이메일 기반으로 비밀번호를 재설정
**So that** 계정을 복구한다

**인수 기준**
- Given 가입된 이메일을 가진 사용자가
- When `/forgot-password`에서 이메일을 입력하면
- Then 재설정 토큰이 포함된 이메일이 발송된다
- And 링크에서 새 비밀번호를 설정하면 즉시 적용된다

## OR. 조직

### US-OR-01: 첫 조직을 생성한다
**As a** 로그인했지만 조직이 없는 사용자
**I want** 새 조직을 생성
**So that** 회사·사업을 등록할 수 있다

**인수 기준**
- Given 어떤 조직에도 속하지 않은 사용자가
- When 조직명과 슬러그(영문 식별자)를 입력하면
- Then `organizations` 레코드가 생성되고
- And 본인이 `org_admin` 역할의 `memberships` 레코드로 등록된다
- And 조직 대시보드(`/app`)로 이동한다

**예외**
- 슬러그 중복: 즉시 인라인 검증
- 슬러그 형식 위반(소문자·숫자·하이픈만): 인라인 에러

---

### US-OR-02: 여러 조직 사이를 전환한다
**As a** 두 개 이상의 조직에 소속된 사용자
**I want** 헤더에서 조직을 전환
**So that** 컨텍스트에 맞는 데이터를 본다

**인수 기준**
- Given 활성 멤버십이 2개 이상인 사용자가
- When 헤더의 조직 선택 드롭다운에서 다른 조직을 선택하면
- Then 페이지가 해당 조직의 대시보드로 전환된다
- And 좌측 사이드바·콘텐츠 모두 해당 조직 데이터로 갱신된다

## ME. 멤버 / 초대

### US-ME-01: 멤버를 초대한다
**As an** 조직 관리자
**I want** 이메일·역할·회사를 지정해 초대 발송
**So that** 다른 사람이 조직에 합류한다

**인수 기준**
- Given 조직 관리자가 멤버 페이지에 진입했고
- When [+ 멤버 초대] 클릭 → 이메일/역할(org_admin·company_member·viewer)/회사 매핑(company_member일 때 필수) 입력 후 [발송]을 누르면
- Then `memberships` 레코드가 `status='invited'`로 생성되고
- And 토큰 링크가 담긴 초대 이메일이 발송된다

**예외**
- 이미 멤버인 이메일: 경고 메시지 + 발송 차단
- company_member 역할인데 회사 미선택: 인라인 에러

---

### US-ME-02: 초대를 수락한다
**As an** 초대받은 사람
**I want** 초대 링크를 통해 가입/로그인 후 합류
**So that** 즉시 데이터에 접근한다

**인수 기준**
- Given 초대 메일을 받은 사람이
- When 링크를 클릭하면
  - 미가입자: 가입 화면(이메일 prefill) → 가입 후 자동 수락
  - 가입자(미로그인): 로그인 후 자동 수락
  - 가입자(로그인): 수락 확인 화면 → [수락]
- Then `memberships.status`가 `active`로 바뀌고 조직 대시보드로 이동

**예외**
- 만료 토큰: "초대가 만료되었습니다. 관리자에게 재요청하세요"
- 다른 사용자가 클릭: "이 초대는 다른 이메일용입니다" 안내

---

### US-ME-03: 멤버 역할을 변경한다
**As an** 조직 관리자
**I want** 멤버의 역할·소속 회사를 변경
**So that** 권한을 조정한다

**인수 기준**
- Given 조직 관리자가
- When 멤버 행의 [편집] → 역할·회사 변경 후 [저장]을 누르면
- Then `memberships.role`과 `company_members` 매핑이 갱신된다
- And 본인의 마지막 org_admin 역할은 변경 불가 (조직에 관리자 최소 1명 보장)

---

### US-ME-04: 멤버를 제거한다
**As an** 조직 관리자
**I want** 멤버를 비활성화
**So that** 더 이상 접근하지 못하게 한다

**인수 기준**
- Given 조직 관리자가
- When 멤버 행 [더보기] → [제거] → 확인 모달에서 [제거]를 누르면
- Then `memberships.status='suspended'`로 변경 (소프트 삭제)
- And 해당 사용자의 활성 세션이 다음 요청에서 차단된다

---

## CO. 회사

### US-CO-01: 회사를 등록한다
**As an** 조직 관리자
**I want** 회사(법인) 정보를 입력해 등록
**So that** 그 회사에 사업을 연결할 수 있다

**인수 기준**
- Given 조직 관리자가 회사 목록 페이지에서
- When [+ 회사 추가] → 회사명·사업자번호·대표자·주소 입력 → [저장]
- Then `companies` 레코드가 생성되고 목록에 표시된다

**예외**
- 사업자번호 형식 위반(10자리/체크섬): 인라인 검증 (경고 수준)

---

### US-CO-02: 회사 정보를 수정한다
**As an** 조직 관리자
**I want** 회사 정보를 수정
**So that** 최신 상태를 유지한다

**인수 기준**
- Given 조직 관리자가 회사 상세 페이지에서
- When 필드 수정 후 [저장]
- Then `companies`가 갱신되고 변경 시각이 기록된다

---

### US-CO-03: 회사를 비활성화한다
**As an** 조직 관리자
**I want** 사용하지 않는 회사를 숨김 처리
**So that** 목록이 깔끔하다

**인수 기준**
- Given 회사에 진행중인 사업이 없는 상태에서
- When 회사 [더보기] → [보관]
- Then 회사가 활성 목록에서 숨김 처리된다
- And 보관 회사 토글 시 다시 표시된다

**예외**
- 진행중 사업이 있으면 보관 불가 → "진행중 사업이 있어 보관할 수 없습니다"

## PR. 사업

### US-PR-01: 새 사업을 등록한다
**As an** 조직 관리자
**I want** 회사 아래 사업 정보(기간·총사업비·재원)를 등록
**So that** 비목과 집행을 기록할 수 있다

**인수 기준**
- Given 회사 상세 페이지에서
- When [+ 사업 추가] → 사업명/주관기관/시작일/종료일/총사업비/선정금액 + 재원 3종(정부지원금/현금/현물)의 계획 금액 입력 → [저장]
- Then `projects` + `funding_sources` 3개 레코드가 생성된다

**예외**
- 재원 3종 합계 ≠ 총사업비: 저장 차단 + 차이 금액 표시
- 종료일 < 시작일: 인라인 에러

---

### US-PR-02: 사업을 수정한다
**As an** 조직 관리자
**I want** 사업 정보·재원을 수정
**So that** 변경된 협약을 반영

**인수 기준**
- Given 사업 설정 탭에서
- When 필드 수정 후 [저장]
- Then 변경 사항이 반영되고 변경 이력이 기록된다 (Phase 2: 변경 이력 UI)

---

### US-PR-03: 사업을 종료/취소 처리한다
**As an** 조직 관리자
**I want** 사업 상태를 `completed`/`cancelled`로 변경
**So that** 완료된 사업이 진행중과 구분된다

**인수 기준**
- Given 진행중인 사업에서
- When [사업 종료] 클릭 → 확인
- Then `status='completed'`로 변경되고 대시보드에서 "종료" 배지 표시
- And 이후 신규 집행 등록은 차단 (수정/조회만 가능)

## BU. 비목

### US-BU-01: 비목을 추가한다
**As an** 조직 관리자
**I want** 사업의 비목과 계획 금액을 입력
**So that** 비목별 집행률을 추적한다

**인수 기준**
- Given 사업의 비목 탭에서
- When [+ 비목 추가] → 비목명·코드(선택)·계획금액·메모 입력 → [저장]
- Then `budget_items` 레코드가 생성된다

**예외**
- 같은 사업 내 비목명 중복: 경고 (허용)
- 비목 계획 금액 합계 > 총사업비: 경고 (허용, 색상 표시)

---

### US-BU-02: 비목을 재정렬한다
**As an** 조직 관리자
**I want** 비목 순서를 드래그로 변경
**So that** 보고서·목록에서 의도된 순서로 노출된다

**인수 기준**
- Given 비목이 2개 이상 있을 때
- When 행을 드래그해 위치 이동
- Then `sort_order`가 즉시 갱신되고 새로고침 후에도 순서 유지

---

### US-BU-03: 비목을 삭제한다
**As an** 조직 관리자
**I want** 비목을 삭제
**So that** 잘못 만든 비목을 제거

**인수 기준**
- Given 해당 비목에 집행 내역이 없을 때
- When [삭제] → 확인 모달
- Then 비목이 삭제된다

**예외**
- 집행 내역이 있으면 삭제 차단 → "집행 N건이 있어 삭제할 수 없습니다"

## EX. 집행 내역

### US-EX-01: 집행 건을 등록한다
**As a** 회사 담당자(또는 조직 관리자)
**I want** 일자·비목·재원·금액·거래처를 입력
**So that** 예산 사용 현황이 실시간 반영된다

**인수 기준**
- Given 사업의 집행 탭에서
- When [+ 집행 추가] → 모달에서 일자·비목·재원유형·금액·거래처·적요 입력 → [저장]
- Then `expenses` 레코드가 생성되고
- And 사업 대시보드의 비목·재원 집행률이 즉시 갱신된다

**예외**
- 사업 종료일 이후 일자: 경고 후 확인 가능
- 비목 잔여액 < 입력 금액: "비목 초과 입력입니다. 계속하시겠어요?" 확인 모달
- 금액 0 또는 음수: 저장 차단

---

### US-EX-02: 집행 건을 수정한다
**As a** 회사 담당자
**I want** 집행 건의 필드를 수정
**So that** 입력 오류를 정정한다

**인수 기준**

- When 행 클릭 → 사이드 패널에서 필드 수정 → [저장]
- Then 즉시 반영되고 변경 시각이 기록된다

---

### US-EX-03: 집행 건을 삭제한다
**As a** 회사 담당자
**I want** 잘못 등록한 집행을 삭제
**So that** 데이터를 정정한다

**인수 기준**
- Given 집행 행에서
- When [더보기] → [삭제] → 확인
- Then 레코드가 삭제되고 대시보드가 갱신된다

---

### US-EX-04: 집행 내역을 필터링한다
**As any** 사용자
**I want** 기간·비목·재원·검색어로 집행을 필터링
**So that** 원하는 건을 빠르게 찾는다

**인수 기준**
- Given 집행 목록 페이지에서
- When 필터 바에서 기간/비목/재원/검색어를 변경
- Then 결과가 즉시 갱신되고 페이지네이션이 1페이지로 리셋된다
- And URL 쿼리스트링에 필터 상태가 반영되어 새로고침 후 복원된다

## DA. 대시보드

### US-DA-01: 조직 대시보드를 본다
**As an** 조직 관리자
**I want** 전 회사·전 사업 요약 카드와 임박 사업 리스트를 본다
**So that** 그룹사 전체 상황을 한눈에 파악

**인수 기준**
- Given 조직 대시보드(`/app`)에 진입했을 때
- Then 다음 정보가 표시된다:
  - 진행중 사업 수, 총사업비 합계, 집행 합계, 잔여 합계, 평균 집행률
  - 회사별 카드 (사업 수, 집행률 게이지)
  - 임박 사업 리스트 (D-30 이내, 집행률 순)

---

### US-DA-02: 사업 대시보드를 본다
**As any** 사업 접근 권한자
**I want** 비목별·재원별 집행률, D-day, 월별 추이를 본다
**So that** 사업 운영 상태를 즉시 파악

**인수 기준**
- Given 사업 상세(`/app/projects/[id]`)에 진입했을 때
- Then 다음이 표시된다:
  - 총사업비/집행/잔여 카드
  - 재원별 게이지(정부지원금/현금/현물)
  - 비목별 집행률 막대 차트
  - 월별 집행 추이 라인 차트
  - 사업 종료까지 D-day 배지

---

### US-DA-03: 권한별로 다른 데이터를 본다
**As a** 회사 담당자
**I want** 본인 소속 회사의 사업만 표시
**So that** 무관한 정보가 안 보인다

**인수 기준**
- Given 회사 담당자(슈퍼런 소속)가 조직 대시보드에 들어왔을 때
- Then 본인 회사(슈퍼런)의 카드와 사업만 표시되고
- And 다른 회사 정보는 카드/리스트 어디에도 나타나지 않는다
- And URL로 다른 회사 사업 ID 접근 시 403 화면 표시

## RP. 리포트

### US-RP-01: 사업별 엑셀을 다운로드한다
**As an** 조직 관리자 / 회계사
**I want** 회사·사업·기간을 선택해 엑셀(XLSX) 파일을 받는다
**So that** 정산 자료로 사용한다

**인수 기준**
- Given 리포트 페이지에서
- When 회사·사업·기간 필터 후 [엑셀 다운로드]
- Then 다음 시트를 포함한 XLSX 파일이 다운로드된다:
  - 시트1: 사업 요약 (총사업비/집행/잔여/재원별)
  - 시트2: 비목별 명세 (계획·집행·잔여)
  - 시트3: 집행 내역 전체 (일자·비목·재원·금액·거래처·적요)
