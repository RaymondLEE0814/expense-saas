## F1. 신규 가입 → 첫 사업 등록 (조직 관리자)

```
[랜딩] → [회원가입 S-AUTH-002]
   ↓ (가입 완료)
[이메일 인증 안내 S-AUTH-005]
   ↓ (메일 링크 클릭)
[로그인 S-AUTH-001]
   ↓
[조직 생성 온보딩 S-ORG-NEW]
   ↓ (생성)
[조직 대시보드 S-ORG-001]  ← 빈 상태: "첫 회사를 추가하세요"
   ↓ ([+ 회사 추가])
[회사 추가 모달 S-COM-001-M01]
   ↓ (저장)
[회사 상세 S-COM-002]  ← 빈 상태: "첫 사업을 추가하세요"
   ↓ ([+ 새 사업])
[사업 등록 Sheet S-PRJ-NEW]
   ↓ (저장)
[사업 대시보드 S-PRJ-001]  ← 빈 상태: "비목을 먼저 등록하세요"
   ↓ ([비목] 탭 → [+ 비목 추가] 반복)
[비목 관리 S-PRJ-003]
   ↓ ([집행] 탭)
[집행 내역 S-PRJ-002]  ← 일상 사용 시작
```

## F2. 멤버 초대 → 회사 담당자 합류

```
[관리자] [멤버 관리 S-MEM-001]
   ↓ ([+ 멤버 초대])
[초대 모달 S-MEM-INVITE] — 이메일/역할/회사 입력
   ↓ (발송)
─────────────────────────────────────
[초대받은 사람의 메일함] → 링크 클릭
   ↓
[초대 수락 S-AUTH-INVITE]
   ├ 미가입자  → [회원가입 S-AUTH-002] (이메일 prefill)
   ├ 가입+미로그인 → [로그인 S-AUTH-001] (이메일 prefill)
   └ 로그인 상태 → 수락 확인 카드
   ↓ (가입 또는 수락)
[조직 대시보드 S-ORG-001]  ← 본인 회사 데이터만 표시
```

## F3. 회사 담당자 일상 — 집행 등록

```
[로그인 S-AUTH-001]
   ↓
[조직 대시보드 S-ORG-001]  ← 본인 회사 사업만 표시
   ↓ (사업 카드 클릭)
[사업 대시보드 S-PRJ-001]
   ↓ ([집행] 탭)
[집행 내역 S-PRJ-002]
   ↓ ([+ 집행 추가])
[집행 모달 S-PRJ-002-M01]
   ↓ (저장)
[집행 내역에 즉시 추가 + 대시보드 캐시 무효화]
```

**주요 인터랙션 포인트**
- 비목 선택 시 잔여액 표시 → 사용자가 초과 여부 즉시 판단
- 초과 입력 시 확인 모달 — UX 마찰을 의도적으로 추가 (실수 방지)

## F4. 월말 정산 — 엑셀 다운로드

```
[조직 대시보드 S-ORG-001]
   ↓ (회사별 점검 — D-day, 집행률)
[사업 대시보드 S-PRJ-001]  ← 사업 1건씩 점검
   ↓ (이상 없으면)
[리포트 S-RPT-001]
   ↓ (회사/사업/기간 선택)
[미리보기]
   ↓ ([엑셀 다운로드])
[XLSX 다운로드]  ← 외부 회계사·주관기관에 전달
```

## F5. 권한 격리 시나리오 (회사 담당자가 다른 회사 사업 직접 URL 접근)

```
[회사 담당자: 슈퍼런 소속] 로그인
   ↓
[URL 직접 입력] /app/projects/<팜큐-사업-uuid>
   ↓
[서버: RLS + can_access_company() → 결과 0건]
   ↓
[404 또는 403 풀페이지]  ← "이 사업에 접근할 권한이 없습니다"
   ↓
[메인으로 가기 버튼]
```

> RLS가 데이터 차단 + 라우트 레이어에서 추가 가드 → 절대 우회 불가.
