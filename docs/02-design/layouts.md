## 1. App Shell (인증 후)

**경로 그룹**: `(app)`, `(admin)`

```
┌─────────────────────────────────────────────────────────────┐
│  [헤더 h-14]                                                │
│  [로고]                  [조직선택 ▾]    [🔔]  [👤이름 ▾]    │
├──────────┬──────────────────────────────────────────────────┤
│          │                                                  │
│ Sidebar  │              Content                             │
│  w-60    │  (max-w-screen-2xl mx-auto p-8)                  │
│          │                                                  │
│  ⌂ 대시보드│                                                  │
│  🏢 회사   │  ┌──────────────────────────────────────┐      │
│  💸 집행   │  │  Page Content                        │      │
│  📊 리포트 │  └──────────────────────────────────────┘      │
│  ─────   │                                                  │
│  👥 멤버   │                                                  │
│  ⚙ 설정   │                                                  │
│          │                                                  │
│          │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

### 1.1 헤더
- 높이 `h-14` (56px)
- 좌측: 로고 (모바일에서만 햄버거 + 로고)
- 가운데/우측: 조직 선택, 알림 벨, 프로필 메뉴
- 배경 흰색, 하단 1px `divider`

### 1.2 사이드바 (데스크톱)
- 너비 `w-60` (240px)
- 배경 `bg-secondary` (#F5F5F7)
- 상단: 로고 영역 (h-14 매칭)
- 메뉴 그룹: 메인 / 운영
- 하단 고정: 프로필 미니 카드

### 1.3 모바일 사이드바
- 햄버거 클릭 시 좌측에서 슬라이드 인
- 백드롭: `rgba(0,0,0,0.4)` blur 8px
- 너비 280px

### 1.4 콘텐츠 영역
- 좌우 패딩: `px-6 md:px-8`
- 최상단 타이틀바: `py-6`, 페이지 제목 + 액션 버튼
- 본문: 카드들 사이 `space-y-6`

## 4. Project Detail Layout (탭 패턴)

사업 상세는 4개 탭 — 콘텐츠 영역 안에서:

```
┌─────────────────────────────────────────────────┐
│  [< 회사로]  스마트팜 실증사업         [⋮ 더보기] │
│  팜큐 · 2025-03-01 ~ 2026-02-28 · D-285        │
├─────────────────────────────────────────────────┤
│  [Overview]  [비목]  [집행]  [설정]              │  ← 탭 헤더
├─────────────────────────────────────────────────┤
│                                                 │
│             탭 콘텐츠                            │
│                                                 │
└─────────────────────────────────────────────────┘
```

- 탭 헤더: 보더 하단 1px, 활성 탭 하단 2px `accent`
- 탭 간격: `px-4 py-3`

## 5. 모달 / 시트 사용 기준

| 상황 | 컴포넌트 |
|------|----------|
| 짧은 확인 (예/아니오) | AlertDialog (작은 모달) |
| 폼 입력 (5필드 이하) | Dialog (480~640px) |
| 폼 입력 (5필드 이상) | Sheet (우측 슬라이드, 480~600px) |
| 상세 보기 (편집 가능) | Sheet 또는 페이지 이동 |
| 임시 정보 표시 | Toast |

## 6. 반응형 브레이크포인트
| 이름 | 너비 | 동작 |
|------|------|------|
| sm | 640px | 모바일 종료 |
| md | 768px | 태블릿 시작 |
| lg | 1024px | 데스크톱 시작, 사이드바 표시 |
| xl | 1280px | 와이드 |
| 2xl | 1536px | 컨테이너 최대치 |

- `< lg`: 사이드바는 햄버거 → 드로어
- `< md`: 테이블은 카드 변환 또는 가로 스크롤
- `< sm`: 모달 풀스크린
