## S-AUTH-001 로그인

**경로**: `/login` | **권한**: 비로그인 (로그인 상태면 `/app` 리다이렉트)

### 와이어
```
┌────────────────────────────┐
│      [로고]                │
│                            │
│      다시 만나서 반가워요   │
│                            │
│      이메일                 │
│      [_______________]     │
│                            │
│      비밀번호               │
│      [_______________] 👁  │
│                            │
│      [    로그인 →    ]    │
│                            │
│      비밀번호 잊으셨나요?    │
│      ────────────────      │
│      처음이신가요? 가입하기  │
└────────────────────────────┘
```

### 컴포넌트
- 카드 너비 448px
- Input: 이메일 / 비밀번호 (보기 토글)
- Primary 버튼 size=`lg`, full width
- 보조: 비밀번호 재설정 링크, 가입 링크

### 동작
- Enter 키로 제출
- 로그인 실패: 카드 상단에 에러 배너 ("이메일 또는 비밀번호가 올바르지 않습니다")
- 미인증 계정: "이메일 인증이 필요합니다" + [인증 메일 재전송] 링크

### 4상태
- 데이터: 로그인 폼
- 빈: N/A
- 로딩: 버튼 내 스피너 + "로그인 중..."
- 에러: 상단 에러 배너 (배경 `danger/10`, 보더 `danger/30`)

## S-AUTH-002 회원가입

**경로**: `/signup` | **권한**: 비로그인

### 와이어
```
┌────────────────────────────┐
│      [로고]                │
│                            │
│      계정 만들기            │
│                            │
│      이름                   │
│      [_______________]     │
│                            │
│      이메일                 │
│      [_______________]     │
│                            │
│      비밀번호 (8자 이상)    │
│      [_______________] 👁  │
│      ━━━━━░░ 강도: 보통    │
│                            │
│      ☐ 이용약관·개인정보 동의│
│                            │
│      [    가입하기 →    ]  │
│                            │
│      이미 계정이 있나요? 로그인│
└────────────────────────────┘
```

### 컴포넌트
- Input 3개 + 약관 체크박스
- 비밀번호 강도 표시 (약/보통/강)
- 약관 텍스트 클릭 시 모달 또는 새 탭

### 동작
- 약관 미동의 시 버튼 비활성
- 가입 성공 → `S-AUTH-005` (이메일 인증 안내)

### 4상태
- 데이터/로딩/에러 동일 패턴
- 빈: N/A

## S-AUTH-004 새 비밀번호 입력

**경로**: `/reset-password?token=...` | **권한**: 토큰 검증

### 와이어
```
┌────────────────────────────┐
│      새 비밀번호 설정       │
│                            │
│      새 비밀번호            │
│      [_______________] 👁  │
│                            │
│      비밀번호 확인           │
│      [_______________] 👁  │
│                            │
│      [   비밀번호 변경    ] │
└────────────────────────────┘
```

### 검증
- 두 입력 일치
- 8자 이상, 영문+숫자

### 동작
- 성공: 토스트 "비밀번호가 변경되었습니다" → `/login`
- 만료 토큰: "재설정 링크가 만료되었습니다. 다시 요청해주세요" + 재요청 버튼

## S-AUTH-INVITE 초대 수락

**경로**: `/invitations/[token]`

### 분기 처리
1. **미가입자**: 가입 화면(`S-AUTH-002`)으로 이동, 이메일 prefill + 토큰 hidden field. 가입 완료 → 자동 수락.
2. **가입자(미로그인)**: 로그인 화면(`S-AUTH-001`)으로 이동, 이메일 prefill + 토큰 query. 로그인 후 자동 수락.
3. **가입자(로그인)**: 수락 카드 표시.

### 가입자(로그인)일 때 와이어
```
┌────────────────────────────┐
│  [조직 로고/이니셜]         │
│                            │
│  (주)슈퍼런 조직의         │
│  멤버로 초대되었습니다       │
│                            │
│  역할: 회사 담당자          │
│  소속: 슈퍼런               │
│  초대자: 이석진 (raymond@…) │
│                            │
│  [  초대 수락       ]      │
│  [  거절          ]        │
└────────────────────────────┘
```

### 에러
- 만료 토큰: "초대가 만료되었어요. 관리자에게 재요청하세요"
- 다른 사용자: "이 초대는 다른 이메일 주소(jane@...)용입니다"
