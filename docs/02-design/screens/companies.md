## S-COM-001 회사 목록

**경로**: `/app/companies` | **권한**: 모든 멤버 (company_member는 본인 회사만)

### 와이어
```
┌───────────────────────────────────────────────────────────┐
│  회사                                  [+ 회사 추가]      │
│  ────                                                     │
│                                                           │
│  [검색...                       ]   [활성만 ▾]            │
│                                                           │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ 회사명       │ 사업자번호    │ 사업수 │ 집행률  │     │  │
│  ├─────────────────────────────────────────────────────┤  │
│  │ 리피치      │ 123-45-67890 │  3     │ ███ 70% │ ⋮  │  │
│  │ 슈퍼런      │ 234-56-78901 │  3     │ ██░ 45% │ ⋮  │  │
│  │ 팜큐        │ 345-67-89012 │  2     │ ███ 60% │ ⋮  │  │
│  └─────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────┘
```

### 컴포넌트
- 검색 인풋 (회사명·사업자번호 부분 일치)
- 필터 (활성/보관/전체)
- 테이블 + 행 더보기 메뉴
- [+ 회사 추가] → 모달

### 행 더보기
- 편집
- 보관 (사업이 없을 때만 활성)
- 진행중 사업 보기

### 모바일
- 카드 변환: 회사명 큰 글씨 + 사업 수 + 집행률 게이지

### 권한
- `company_member`: 본인 소속 회사만 표시, [+ 회사 추가] 버튼 hidden
- `viewer`: 버튼 hidden, 메뉴에서 편집·보관 hidden

### 4상태
- 빈: "아직 등록된 회사가 없습니다 / + 회사 추가" 일러스트

```
┌─────────────────────────────────────┐
│  회사 추가                    [×]   │

│                                     │
│  회사명 *                           │
│  [_______________________________]  │
│                                     │
│  사업자번호                          │
│  [123-45-67890_____________]       │
│  형식이 올바르지 않습니다 (선택)      │
│                                     │
│  대표자                             │
│  [_______________________________]  │
│                                     │
│  주소                               │
│  [_______________________________]  │
│                                     │
│  메모                               │
│  [_______________________________]  │
│  [_______________________________]  │
```

## S-COM-002 회사 상세 + 사업 목록

**경로**: `/app/companies/[id]`

### 와이어
```
┌───────────────────────────────────────────────────────────┐
│  ← 회사                                       [⋮ 회사 편집]│
│  ────                                                     │
│  리피치 (Repeach)                                          │
│  사업자번호 123-45-67890 · 대표 이석진                      │
│                                                           │
│  ┌──────────┬──────────┬──────────┐                       │
│  │ 사업 수   │ 총사업비  │  집행률   │                       │
│  │  3건     │ ₩8.8억   │   70%    │                       │
│  └──────────┴──────────┴──────────┘                       │
│                                                           │
│  사업                                    [+ 새 사업]      │
│  ──                                                       │
│                                                           │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ 사업명          │ 기간           │ 상태 │ 집행률│      │  │
│  ├─────────────────────────────────────────────────────┤  │
│  │ AI 콘텐츠 R&D  │ 25.04~26.03   │ 진행중│ ██ 82%│ →  │  │
│  │ 디지털 트윈      │ 25.07~26.06   │ 진행중│ █░ 30%│ →  │  │
│  │ TIPS R&D        │ 24.01~24.12   │ 종료  │ █░ 95%│ →  │  │
│  └─────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────┘
```

### 컴포넌트
- 헤더: 뒤로가기, 회사명, 회사 정보 (보조 텍스트), 우측 [편집] 메뉴
- KPI 카드 3개
- 사업 목록 테이블 (행 클릭 → 사업 상세)
- [+ 새 사업] → 사업 등록 모달 (S-PRJ-NEW)

### 상태 배지
- 진행중: 초록 칩
- 종료: 회색 칩
- 취소: 빨강 칩 (희소 사용)

### 권한
- `company_member` (소속): [편집] 메뉴 숨김 (조직 관리자만)
- `company_member` (비소속): 라우트 자체 차단 (403)
