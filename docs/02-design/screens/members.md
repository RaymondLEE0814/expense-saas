## S-MEM-001 멤버 관리

**경로**: `/app/members` | **권한**: org_admin 만 (그 외는 사이드바에서 항목 hidden + 라우트 403)

### 와이어
```
┌─────────────────────────────────────────────────────────────┐
│  멤버                                          [+ 멤버 초대] │
│  ──                                                          │
│                                                             │
│  활성 (5)    초대 대기 (1)    비활성 (0)                     │
│  ──────────                                                 │
│                                                             │
│  ┌─────────────────────────────────────────────────────────┐│
│  │ 이름        │ 이메일             │ 역할       │ 회사     ││
│  ├─────────────────────────────────────────────────────────┤│
│  │ 이석진(나)  │ raymond@repeach.kr │ 조직 관리자 │ 전체    ⋮││
│  │ 김민지     │ minji@superrun.io  │ 회사 담당자 │ 슈퍼런  ⋮││
│  │ 박철수     │ chulsoo@farmq.io   │ 회사 담당자 │ 팜큐    ⋮││
│  │ 이지원     │ jiwon@repeach.kr   │ 회사 담당자 │ 리피치  ⋮││
│  │ 박세무회계 │ park@cpa.co.kr     │ 조회자     │ 전체    ⋮││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

### 컴포넌트
- 탭: 활성 / 초대 대기 / 비활성 (개수 배지)
- 테이블: 이름·이메일·역할·회사
- 행 ⋮: 편집(역할·회사 변경) / 제거
- "나" 라벨 (본인 행)

### 동작
- 자기 자신은 [제거] 비활성, 본인이 유일한 org_admin이면 [편집] 비활성 (역할 변경 불가)

### 모바일
- 카드 변환: 이름 + 이메일 (작게) + 역할/회사 배지

## S-MEM-INVITE 멤버 초대 모달

```
┌──────────────────────────────────────────┐
│  멤버 초대                          [×]  │
│  ──────                                  │
│                                          │
│  이메일 *                                │
│  [minji@superrun.io____________________] │
│                                          │
│  역할 *                                  │
│  ⦿ 조직 관리자  — 모든 권한                │
│  ◯ 회사 담당자  — 지정 회사만 CRUD         │
│  ◯ 조회자      — 전체 읽기 전용            │
│                                          │
│  소속 회사 *   (회사 담당자만)              │
│  [□ 리피치] [☑ 슈퍼런] [□ 팜큐]            │
│  ⓘ 회사 담당자는 선택한 회사의 데이터만     │
│    수정·열람할 수 있습니다                  │
│                                          │
│  메시지 (선택)                            │
│  [_____________________________________] │
│  초대 메일에 함께 발송됩니다                │
│                                          │
│              [취소]  [   초대 보내기   ]  │
└──────────────────────────────────────────┘
```

### 검증
- 이메일 형식
- 같은 조직 활성/대기 멤버 중복: 인라인 에러
- 회사 담당자인데 회사 미선택: 인라인 에러

### 동작
- 발송 후: 모달 닫힘, 토스트 "minji@superrun.io 에게 초대 메일을 보냈어요"
- 초대 대기 탭에 즉시 추가

## S-MEM-001-E01 멤버 편집 (인라인 Sheet)

행 클릭 또는 ⋮ → 편집:

```
┌────────────────────────────┐
│  멤버 편집           [×]   │
│  ─────                     │
│                            │
│  김민지                    │
│  minji@superrun.io         │
│                            │
│  역할                       │
│  [회사 담당자 ▾]            │
│                            │
│  소속 회사                  │
│  [☑ 슈퍼런] [□ 팜큐] ...   │
│                            │
│  ─── 위험 영역 ──────       │
│  [멤버 제거]                │
│                            │
│       [닫기]   [저장]      │
└────────────────────────────┘
```

### 멤버 제거 확인
```
┌──────────────────────────────┐
│  김민지를 제거하시겠어요?     │
│  이 작업은 되돌릴 수 있어요    │
│  (비활성 → 다시 활성 가능)    │
│           [취소]  [제거]     │
└──────────────────────────────┘
```
