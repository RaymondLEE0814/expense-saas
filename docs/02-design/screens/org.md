### 컴포넌트
1. **KPI 카드 4개** — 진행중 사업/총사업비/집행/잔여
2. **회사별 카드 그리드** — 회사명, 사업 수, 집행률 게이지(progress bar), 집행/총사업비
3. **임박 사업 리스트** — D-30 이내 사업, D-day 배지(노랑/빨강), 집행률
4. **최근 활동 리스트** — 최근 10건 집행

### 컴포넌트 상세
- KPI 카드: `Card`, height 100~110px, 큰 숫자 `text-title-1`, 라벨 `caption fg-secondary`
- 회사 카드: 클릭 시 회사 상세로 이동, hover shadow
- 임박 사업 행: 호버 강조, 클릭 시 사업 상세 이동
- D-day 배지: D-30~D-7 노랑(warning), D-7 이내 빨강(danger)

### 4상태
- **데이터**: 위 와이어
- **빈** (사업 0건): 큰 일러스트(없으면 큰 + 아이콘) + "첫 사업을 등록하세요" + [+ 사업 추가] CTA
- **로딩**: 카드 4개 스켈레톤 + 회사 카드 3개 스켈레톤
- **에러**: 페이지 중앙 에러 + 새로고침 버튼

### 권한별 차이
- `org_admin`: 위 와이어 전체
- `company_member`: 본인 회사 1개만 회사 카드에 표시, KPI는 본인 회사 사업만 합산
- `viewer`: 위 와이어 전체 읽기 전용 (CTA 버튼 hidden)

### 모바일
- KPI 카드: 2x2 그리드
- 회사 카드: 1열 세로
- 임박/활동: 동일
