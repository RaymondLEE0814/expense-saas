### 컴포넌트
1. 헤더: 회사 뒤로, 사업명, 메타(기간/상태/D-day), [⋮ 사업 종료/취소/삭제]
2. 탭 (4개)
3. KPI 카드 3개
4. 재원별 게이지 — Apple 스타일 progress bar
5. 비목별 막대 — Recharts BarChart (수평)
6. 월별 추이 — Recharts LineChart (월 단위 합계 + 누적 점선)
7. 최근 집행 — 5건

### 색상 / 경고
- 비목 95% 초과: 노란 게이지 + ⚠ 아이콘
- 100% 초과: 빨간 게이지 + ⚠
- D-30 이내: D-day 텍스트 노랑
- D-7 이내: 빨강

### 4상태
- 빈 (비목 0개): "비목을 먼저 등록하세요" + [비목 추가] CTA
- 빈 (집행 0건): KPI는 0으로 표시, 비목 차트는 계획만 보임, 최근 집행 영역에 빈 안내
- 로딩: 카드/차트 스켈레톤
- 에러: 영역별 에러 + 새로고침

### 컴포넌트
- 필터바: 기간 DateRangePicker / 비목 멀티 / 재원 멀티 / 검색 input
- 결과 헤더: 건수 + 합계
- 테이블: 정렬 가능(일자/금액)
- 행 클릭: 우측 Sheet 열림 (편집)
- 행 ⋮: 편집 / 삭제
- 페이지네이션 + 페이지당 선택 (50/100)

### URL 상태
- `?from=2026-01-01&to=2026-05-31&budget=uuid1,uuid2&source=gov_grant&q=인건비&page=2`

### 4상태
- 빈 (전체): "아직 집행 내역이 없습니다 / + 집행 추가" 일러스트
- 빈 (필터 결과 0): "조건에 맞는 결과가 없습니다 / 필터 초기화"
- 로딩: 테이블 행 스켈레톤 5개
- 에러: 영역 에러 + 재시도
