## S-RPT-001 리포트 / 엑셀

**경로**: `/app/reports` | **권한**: 모든 멤버 (company_member는 본인 회사만)

### 와이어
```
┌─────────────────────────────────────────────────────────────┐
│  리포트                                                      │
│  ────                                                       │
│                                                             │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  데이터 범위                                             │ │
│  │  ────────                                              │ │
│  │                                                        │ │
│  │  회사   [전체 ▾]                                        │ │
│  │  사업   [전체 ▾  (또는 사업 다중 선택)]                  │ │
│  │  기간   [2026-01-01]  ~  [2026-05-31]                  │ │
│  │                                                        │ │
│  │  포함 시트                                              │ │
│  │  ☑ 사업 요약                                            │ │
│  │  ☑ 비목별 명세                                          │ │
│  │  ☑ 집행 내역 전체                                       │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                             │
│  미리보기                                                    │
│  ────                                                       │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  사업: 3개 · 비목: 28개 · 집행: 412건                    │ │
│  │  합계: ₩1,240,000,000                                  │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                             │
│                           [   엑셀 다운로드 ↓   ]            │
└─────────────────────────────────────────────────────────────┘
```

### 동작
- 필터 변경 → 미리보기 즉시 갱신 (count + 합계)
- [엑셀 다운로드] 클릭 → 서버에서 XLSX 생성 후 다운로드
- 다운로드 중 버튼 로딩 상태

### XLSX 시트 구성

**시트 1: 사업 요약**
| 회사 | 사업명 | 기간 | 총사업비 | 정부지원금 계획 | 정부지원금 집행 | 현금 계획 | 현금 집행 | 현물 계획 | 현물 집행 | 잔여 | 집행률 |

**시트 2: 비목별 명세**
| 회사 | 사업명 | 비목명 | 비목코드 | 계획 | 집행 | 잔여 | 집행률 |

**시트 3: 집행 내역**
| 일자 | 회사 | 사업 | 비목 | 재원 | 금액 | 거래처 | 적요 | 증빙 유형 | 등록자 | 등록일시 |

### 4상태
- 데이터: 위 와이어
- 빈 (선택 사업 없음): "사업을 선택해주세요"
- 로딩 (다운로드): 버튼 스피너 + "엑셀 생성 중..."
- 에러: 토스트 + 재시도

### 권한
- `company_member`: 회사 선택지가 본인 회사로 잠김
- `viewer`: 동일 사용 가능, 다운로드도 가능
